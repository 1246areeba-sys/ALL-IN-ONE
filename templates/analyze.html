How it works

  1. Data Loading — both CSV datasets are read with pandas.
  2. Data Understanding — shapes, nulls and distributions are inspected.
  3. Data Cleaning — messy text (prices, rates) parsed to numbers; non-predictive columns dropped.
  4. Fill & Drop — missing targets dropped; numeric nulls filled with median, categorical with mode.
  5. Convert — categoricals label-encoded, features standard-scaled.
  6. Split — 80/20 train/test.
  7. Model — RandomForestRegressor trained and saved as .pkl.
